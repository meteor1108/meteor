# Fitness App 版本记录

## v2.2 - 65kg个人初始值

- 按65kg、有训练基础、增肌、练三休一设置保守起始重量。
- 阶段目标调整为69kg，截止日期2027-06-30，对应约0.15%体重/周。
- 第一次训练以RIR 3校准，后续恢复为计划RIR 2并按实际记录进阶。

## v2.1 - 动作图例与休息说明

- 为16个训练动作换成一一对应的姿势/器械图例。
- 明确橙色身体、灰色器械的图例含义。
- 正式组记录后自动启动组间计时，并加入暂停、跳过和增加30秒。

## v2 - 训练科学升级

- 按增肌目标重排 Push / Pull / Legs 动作、组数、次数、RIR 与休息。
- 加入保守起始重量、热身组与正式组区分、按器械独立保存重量。
- 加入自动渐进、连续退步减重、疼痛冻结与恢复减量规则。
- 加入训练快照、晨重趋势、营养最低线和 JSON 导入导出。
- 加入组间计时、中断位置保存和腿弯举器械确认。
