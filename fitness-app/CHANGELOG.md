# Fitness App 版本记录

## v3.2 - 轻材质训练与饮食界面

- 训练页改为透明、半透明薄材质，让背景图保持可见，并减少渐变、胶囊和装饰元素。
- 今日训练加入动态圆环；每完成一个动作，完成数与圆环进度同步更新。
- 日历当天直接标出训练类型，补齐训练前热身与训练后拉伸动作。
- 饮食页改为紧凑营养总览与分隔列表，保留既有餐食、营养数据和记录功能。
- 更新离线缓存版本，避免手机版继续加载旧界面。

## v2.10 - 打卡动画可见性修复

- 打卡组件进入首页时与营养、目标天数使用同款模糊变清晰动画。
- 打卡成功后显示明显的绿色勾、卡片高亮、按钮弹动和数字变化。

## v2.9 - 今日打卡动画

- 完成今日训练时，按钮轻微缩放并切换为已完成状态。
- 连续打卡和累计打卡数字从旧值逐步变为新值。
- 保留营养卡片和目标天数的模糊出现、数字递增和进度填充动画。

## v2.8 - 训练与营养动态展示

- 今日训练标题和动作列表逐项由模糊变清晰。
- 营养蛋白质数字从0递增到当日实际摄入，进度条同步填充。

## v2.7 - 启动页与首页改版

- 启动页自动展示今日推、拉、腿或休息计划，包含动作名称、组次范围和当前重量。
- 新增简洁的淡入上移开场动画，并保留底部「进入」按钮。
- 首页删除「去健身房」，压缩营养卡片，合并训练打卡与连续/累计数据。
- 点击进入后，营养摄入和目标天数依次从模糊过渡为清晰。

## v2.6 - 14天晨重趋势

- 新增最近14条晨重折线、逐日涨跌和记录进度。
- 展示前7日、后7日平均值以及两组平均变化百分比。
- 明确显示热量调整原因、生效日期、饮食记录要求和剩余记录天数。
- 保存晨重后显示日期与体重确认，异常数值不会写入历史。

## v2.5 - 智能重量与一键组记录

- 自动根据上次正式组生成本次建议重量、次数和目标 RIR。
- 每组增加“一键完成”，正常训练不再重复输入；实际表现不同时仍可修改。
- 完成正式组后自动启动该动作休息计时，热身组默认休息 60 秒。
- 保留热身组/正式组区分、疼痛冻结、历史快照和保守渐进规则。

## v2.4 - 完整营养进度

- 饮食页新增每日热量、碳水和脂肪进度，并保留蛋白质进度。
- 四项进度均读取当前体重、增肌/减脂目标与晨重趋势计算的每日目标。

## v2.3 - 精简食物库与补剂提醒

- 精简为用户常用食物，并加入白菜、青菜、香菇青菜包、高蛋白面包和咖喱鸡排饭。
- 蛋白粉按每勺30g、蛋白质22.5g录入并仅放在加餐；咖喱鸡排饭也仅放在加餐，面包按50g、约132kcal录入。
- 饮食页加入肌酸与蛋白粉使用时间、训练/休息日提示和每日完成打卡。

## v2.2 - 65kg个人初始值

- 按65kg、有训练基础、增肌、练三休一设置保守起始重量。
- 阶段目标调整为69kg，截止日期2027-06-30，对应约0.15%体重/周。
- 第一次训练以RIR 3校准，后续恢复为计划RIR 2并按实际记录进阶。

## v2.1 - 动作图例与休息说明

- 为16个训练动作换成一一对应的姿势/器械图例。
- 明确橙色身体、灰色器械的图例含义。
- 正式组记录后自动启动组间计时，并加入暂停、跳过和增加30秒。

## v2 - 训练科学升级

- 按增肌目标重排 Push / Pull / Legs 动作、组数、次数、RIR 与休息。
- 加入保守起始重量、热身组与正式组区分、按器械独立保存重量。
- 加入自动渐进、连续退步减重、疼痛冻结与恢复减量规则。
- 加入训练快照、晨重趋势、营养最低线和 JSON 导入导出。
- 加入组间计时、中断位置保存和腿弯举器械确认。
